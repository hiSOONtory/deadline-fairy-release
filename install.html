마감요정 v1.6

마감요정, 그림 보고 따라 하면 끝나요

어려운 말은 하나도 몰라도 괜찮아요. 빨간 동그라미가 있는 곳만 누르면 됩니다.

처음 설치해요마감요정을 한 번도 안 써 봤어요 · 5단계 새 버전으로 바꿔요이미 쓰고 있어요 · 4단계, 목록은 그대로

처음 설치하기 5분이면 돼요

1

아래 빨간 버튼을 누르세요

파일 하나가 내려받아져요. 이름은 deadline-fairy-v1.6.zip이에요. (마감요정의 영어 이름이에요)

⬇ 마감요정 받기 약 52MB · 윈도우 PC용
창이 안 보이면 괜찮아요. 파일 탐색기 → 다운로드 폴더에 들어가 있어요.
2

안에 있는 마감요정 폴더를 바탕화면으로 끌어다 놓으세요

파일을 열면 노란 폴더가 하나 보여요. 마우스로 꾹 누른 채 바탕화면에 놓으면 돼요.

압축 파일 안에서 바로 실행하면 안 돼요. 꼭 바탕화면(또는 문서)으로 꺼낸 다음 실행하세요.
3

바탕화면의 마감요정 폴더를 열고 마감요정.exe를 두 번 누르세요

요정 그림이 붙은 파일이에요. 다른 파일은 건드리지 않아도 돼요.

4

파란 경고 창이 뜨면 추가 정보 → 실행

처음 한 번만 떠요. 학교에서 만든 프로그램이라 윈도우가 아직 몰라서 그래요. 위험한 게 아니에요.

"게시자: 알 수 없음"이라고 나와도 괜찮아요. 실행을 누르세요.
5

화면 오른쪽에 마감요정이 나타나면 성공!

이제 브리티에서 쪽지를 열어서 읽기만 하면, "~까지 제출"이 적힌 쪽지가 알아서 목록에 들어와요.

설치 끝 🎉

창을 닫아도 꺼지지 않아요. 작업표시줄 오른쪽 요정 아이콘을 누르면 다시 열려요.

새 버전으로 바꾸기 마감 목록·할 일은 그대로 남아요

1

켜져 있는 마감요정을 먼저 종료하세요

작업표시줄 오른쪽 ^ 를 누르고 → 요정 아이콘을 오른쪽 버튼으로 누르고 → 마감요정 종료.

왜 꺼야 하나요? 켜져 있으면 파일을 바꿀 수가 없어서예요.
2

새 파일을 받으세요

처음 설치할 때와 똑같아요. 이 버튼을 누르면 돼요.

⬇ 새 마감요정 받기 deadline-fairy-v1.6.zip · 약 52MB
3

새 마감요정 폴더를 원래 있던 곳에 끌어다 놓고 → 바꾸기

보통은 바탕화면이에요. "파일 바꾸기" 창이 뜨면 대상에 있는 파일 바꾸기를 누르세요.

걱정 마세요. 마감 목록·할 일·휴지통·설정 파일은 새 파일에 들어 있지 않아서 지워지지 않아요.
4

마감요정.exe를 다시 두 번 누르세요

작업표시줄의 요정 아이콘에 마우스를 올렸을 때 마감요정 v1.6이라고 나오면 업데이트 끝이에요.

막혔을 때

받기 버튼을 눌렀는데 "일반적으로 다운로드되지 않습니다"라고 떠요

파일 이름 옆 … 을 누르고 → 유지 → 그래도 계속을 누르세요. 새 프로그램이라 브라우저가 한 번 물어보는 거예요.

받기 버튼을 눌렀더니 "404"나 GitHub 로그인 화면이 나와요

파일을 올린 선생님께 알려 주세요. 파일을 받을 수 있는 상태가 아니라는 뜻이에요. 로그인은 하지 않아도 돼요.

받은 파일이 어디 있는지 모르겠어요

키보드의 ⊞ Windows + E 를 같이 누르면 파일 탐색기가 열려요. 왼쪽에서 다운로드를 누르면 있어요.

실행했는데 아무것도 안 떠요

이미 켜져 있을 수 있어요. 작업표시줄 오른쪽 ^ 안의 요정 아이콘을 눌러 보세요. 그래도 안 되면 폴더를 C:\Program Files가 아닌 바탕화면에 두었는지 확인하세요.

쪽지가 목록에 안 들어와요

쪽지를 직접 열어서 읽어야 들어와요. 그리고 "9월 18일까지 제출"처럼 날짜와 할 일이 같이 있어야 해요. 내가 보내는 쪽지는 보내는 순간 들어와요.

구글 캘린더랑 연결하고 싶어요

안 해도 다른 기능은 다 돼요. 원하시면 마감요정 폴더 안의 읽어주세요.txt [3]번에 방법이 있어요.
